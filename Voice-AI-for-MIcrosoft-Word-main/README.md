#  Voice AI for Microsoft Word

Voice AI for Microsoft Word is an AI-powered desktop application developed in Python that allows users to create and edit Microsoft Word documents using voice commands. It also includes AI-powered tools for generating presentations, invitations, essays, and answering user queries, making document creation faster and more efficient.

## Features

- Voice-controlled Microsoft Word document creation
- Real-time document editing using voice commands
- Automatic image search and insertion into documents
- AI-powered PowerPoint presentation generator
- Automatic invitation card generator
- AI-based essay and content generation
- ChatGPT integration for instant answers and writing assistance
- User-friendly graphical interface (GUI)
- Document formatting with borders, headings, and styling
- Faster and hands-free document creation
